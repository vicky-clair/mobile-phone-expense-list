# 每日费用日志与邮箱配置（0.2.0）

2026-09-27 用户变更：软件名为“费用统计清单”；按北京时间每天生成费用日志并发送指定邮箱，发送后删除本机日报文件；解锁只用手机已有锁屏密码、PIN 或图案，不使用指纹。本需求替代原 v1.3 文档中的每周网关邮件和优先指纹方案。

## 手机端配置

1. 先设置手机的锁屏密码/PIN/图案。打开应用和进入邮箱配置需系统凭据认证。
2. 在邮箱服务商处开启 SMTP 并获得专用授权码。进入本应用“设置 → 每日费用日志与邮箱设置”。不要将授权码发到聊天或写入源码。
3. 按服务商提供的信息填写主机、端口、登录账号、授权码、发件地址和一个收件地址。隐式 TLS 通常使用 465；STARTTLS 通常使用 587。两种模式都强制 TLS 和服务器证书校验，不支持明文 SMTP。
4. 保存设置后发送测试邮件。测试附件不包含账目；发送使用已保存配置。确认收件箱/垃圾邮件后启用“每日邮件”并保存。
5. 状态在最近 50 条发送记录中展示。连接或认证失败会退避重试，修正配置后可能需要等待当前后台重试。

仅支持用户名/授权码 SMTP 登录；要求 OAuth2 的邮箱租户不能直接用此配置登录。发件地址应符合邮箱服务商授权规则。

## 时间、内容和删除语义

- 固定 Asia/Shanghai 时区，每份报告包含该日 00:00（含）至次日 00:00（不含），即北京时间 24 小时，不随手机切换时区改变。
- 首次启用从当天开始，次日约 00:05 生成和发送。关闭后保存会暂停日报；重新启用从当天恢复。已生成的待发日报会在恢复后继续发送。测试邮件是显式操作，日报关闭时也可发送。
- WorkManager 每 24 小时执行生成检查。系统休眠、关机、强停可能延后；下次执行会按持久游标逐日补生成，每批最多 31 日。生成不依赖网络，发送有网络约束及指数退避，不能承诺零点准时发出。
- 每天生成一个 UTF-8 BOM CSV，即使无账目也生成零汇总。含已确认支出/收入/退款、待核对笔数及商户/金额/分类/类型/状态/渠道明细；待核对不计已确认汇总，转账/还款不计支出，已忽略账目不导出。
- 文件是执行生成时的不可变快照。延迟生成会使用当时的账本；已生成后补录或改账不会改写历史日报或自动重发。预览昨日反映当前账本，可能不同于历史快照。
- SMTP DATA 返回成功后，先持久记录服务器已接收，再删除私有目录内该日报 CSV；清理中断会在下次执行继续清理。记录保留状态、日期、地址、时间与摘要，不保留 CSV 正文。
- **删除的是本机日报附件文件，不是原账本，不是手动导出文件，也不是邮箱副本。** 文件普通删除不意味着对闪存作安全擦除。账本仍可查看、补录及导出。

## 重复与失败

- 每日唯一 ID 防止重复生成；文件原子写入，发送前校验内容摘要。数据库与生成游标之间中断，恢复后使用已有报告，不重复生成。
- 连接/认证失败发生在提交前，保留文件并重试。
- 开始发送前持久记录 SENDING。若发送中断或响应丢失，标记 UNKNOWN（结果不明），停止自动重发。SMTP 没有网关幂等能力，固定 Message-ID 也不保证邮箱去重。
- 检查收件箱后，可选“我已收到，清理文件”或“未收到，重新发送”。重发会明确提示重复风险。
- “服务器已接收”不表示已经投递到收件箱。后续退信无法由本应用自动获知。
- 有未完成邮件时禁止更改收件地址，避免旧日志被无提示转发给新地址。可处理旧邮件，或明确清除邮箱配置与日报数据后重新设置。
- “清除邮箱配置与日报文件”停止日报并清除待发文件、记录及配置，保留原账本；“删除全部本地数据”同时清除原账本。已发或正在发送的邮件无法撤回。

## 数据及技术

主账本 Room v1 不变，新增独立 reports.db / ReportDatabase v1，无破坏性迁移。报告文件保存在应用 noBackupFilesDir/daily-reports；账号、授权码、邮箱等整个配置使用 Android Keystore AES-GCM 加密保存，后台发送不依赖 UI 解锁。账本和待发 CSV 本身未加密，系统备份和设备迁移保持禁用。密钥丢失时通过界面清除邮件数据并重新填写配置，不静默降级为明文。

邮件使用 Eclipse Angus Mail；WorkManager 负责重启后的任务调度。不得把真实授权码硬编码或写日志。本项目没有配置真实账号、没有发送真实费用邮件；需在用户手机上完成实际 SMTP、密码交互及后台验收。

参考：[Android WorkManager 周期任务](https://developer.android.com/reference/androidx/work/PeriodicWorkRequest)、[Angus Mail Android](https://eclipse-ee4j.github.io/angus-mail/Android)、[SMTP 配置](https://eclipse-ee4j.github.io/angus-mail/docs/api/org.eclipse.angus.mail/org/eclipse/angus/mail/smtp/package-summary.html)。
