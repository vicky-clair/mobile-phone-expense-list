# 费用统计清单

[English（主文档）](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

使用 Kotlin、Jetpack Compose、Room、DataStore 和 WorkManager 开发的原生 Android 记账应用。当前为 **0.3.0 开发版**，最低 Android 13，界面与安装名称为中文。不限制手机品牌，但尚未完成真机兼容性验收。

## 主要功能

- 本地账本：补录、分类、搜索、确认、忽略/撤销、修订历史、CSV 导出及删除，金额使用整数分。
- 通知采集：主动选择来源、系统通知使用权、有界队列、完全相同事件去重及可能重复核对。
- 应用锁：仅使用手机锁屏密码、PIN 或图案，不调用指纹；进入后台立即锁定，采集与日报仍可运行。
- 自适应界面：窄窗口单栏，宽窗口列表与明细双栏。
- 提醒控制：总开关，以及成功、待确认、操作结果弹出提示开关；关闭清理已有提醒并阻止新提醒。
- 每日日志：北京时间自然日 CSV、个人 SMTP 发送、发送状态记录，服务器接收后删除本机日报文件并保留原账本。
- 测试面板：微信、支付宝、银行模拟各四种场景，共 12 项；另有提醒测试与邮件发送测试。

## 当前边界

微信和支付宝只有合成样本实验规则，识别结果需要人工确认。银行测试是隔离模拟，不表示已支持真实银行通知。模拟测试不发起付款，不写入账本或日报。

系统休眠、关机、强停或断网会延后执行，不能保证准点发送。SMTP 服务器接收不等于投递到收件箱；提交中断后若结果不明，需要先检查邮箱，再决定确认收到或重发。

应用锁不等于数据加密。SMTP 配置使用 Android Keystore 加密，主账本与待发 CSV 本身未加密；系统备份和设备迁移已禁用。真实通知、密码交互、Keystore 和实际邮箱投递仍需真机验证。

## 构建与安装

需要 JDK 17、Android SDK API 37、Build Tools 36.1.0。项目固定 Gradle 9.3.1、AGP 9.1.1、Compose Kotlin 插件 2.2.10、KSP 2.3.9，minSdk 33、targetSdk 36。

设置 `ANDROID_HOME`，或在本地 `local.properties` 设置 `sdk.dir`。Windows 项目目录执行：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --console=plain
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，可以使用手机文件管理器安装，或对已授权调试的设备执行：

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

升级时保持 `cn.foldledger` 包名与签名一致。当前没有发布签名配置。临时 API 36 编译可添加 `-Pledger.compileSdk=36`，不能替代真机兼容性测试。

## 首次使用

1. 先设置手机锁屏密码、PIN 或图案，启动应用后输入系统凭据。
2. 在“设置”选择来源、开启采集，再到系统设置授权“通知使用权”。默认不采集且不选择来源。
3. 核对或编辑识别结果后才计入正式金额；缺失及不支持的交易手动补录。
4. 在“提醒”调整总开关和分类开关。关闭提醒不停止采集或每日邮件；邮件有独立开关。系统认证、删除确认和主动查看的结果仍保留。
5. 在“支付与收款测试”选择来源和场景，修改金额后加载示例，也可编辑脱敏通知正文；运行单项或一键测试 12 项。提醒测试遵循开关及系统权限。
6. 进入“每日费用日志与邮箱设置”再次认证，保存 SMTP 主机、端口、账号、授权码、发件及收件邮箱。先发测试邮件，收到后再启用每日邮件。不要把真实授权码写进源码、聊天或日志。

## 日报规则

- 固定 `Asia/Shanghai` 时区，每日 00:00（含）至次日 00:00（不含）。启用从当天开始，首次日报次日生成，初始计划约 00:05 执行，延迟后逐日补生成。
- 日报包含确认汇总与明细；待核对独立标注，转账/还款不计支出，已忽略项不进入日报。
- 已生成文件为不可变快照，后续补录或修订不自动改写或重发；昨日预览读取当前账本，可能与历史快照不同。
- 支持隐式 TLS 与 STARTTLS，始终验证证书；仅支持账号/授权码登录，不支持只允许 OAuth 的账号流程。
- 服务器接受后删除的仅是**本机日报附件文件**。原账本、发送元数据保留，邮箱副本与手工导出文件不受影响。

配置与异常处理详见[每日邮件说明](docs/DAILY_MAIL.md)。
